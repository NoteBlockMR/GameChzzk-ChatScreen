# OBS Lua 채팅 수신 확장 (실험 버전)

**Python 수신기 없이 OBS 내부 Lua가 직접 치지직 채팅을 받습니다.** LuaJIT FFI로 OBS에 포함된 libcurl의 HTTPS/WebSocket 기능을 사용합니다. 메시지 표시만 OBS 브라우저 소스(HTML/JavaScript)가 담당합니다. 기존 독립 실행형 앱/1.1.7 릴리즈는 변경하지 않았습니다.

## v0.1.3 변경 사항

- 선택형 Java/soop4j 애드온으로 치지직·SOOP 일반 채팅을 함께 표시합니다.
- 플랫폼 이름·색상을 구분하고 두 수신 경로를 독립적으로 갱신합니다.
- SOOP 재연결 시 메시지가 사라지는 문제를 수정했습니다. 애드온 HTTP 응답은 30초까지 일시 실패를 허용합니다.
- 기본 Lua 패키지는 Java 없이 사용할 수 있습니다. SOOP 사용자는 애드온 포함 패키지와 Java 11 이상이 필요합니다.

## v0.1.2 변경 사항

- 녹화 화면의 나란히 / 중첩 배치를 선택할 수 있습니다.
- OBS에 등록된 가상 카메라를 장치 목록과 이름으로 감지해 합성 장면에 추가합니다.
- 공식 후원 알림·영상 후원·미션 후원 오버레이 주소와 개별 표시 설정을 지원합니다.
- 개발자 앱 등록은 필요하지 않으며, 후원 기능의 주인 로그인 여부를 검증하지 않습니다.
- 배치·가상 카메라·후원 표시 검증은 API 모의 테스트입니다. 실제 카메라 영상과 후원 재생·효과음은 OBS에서 확인하세요.

## v0.1.1 변경 사항

- 연결 오류 후 인증이 다시 완료되면 `CHZZK 재연결 완료: 채팅 수신을 재개합니다.` 안내를 한 번 출력합니다.
- 오류 56 발생 → 대기 → 재인증 → 채팅 수신 재개 과정을 모의 테스트로 확인했습니다. 연결 끊김 자체의 원인을 해결한 변경은 아닙니다.
- 업데이트 시 ZIP 전체를 새 폴더에 풀고 OBS 스크립트를 해당 폴더의 `chzzk-chat.lua`로 다시 등록하세요.

## 실행

1. `obs-plugin` 폴더 전체를 보관하세요. `chzzk-chat.lua`와 `chzzk_receiver.lua`, `chzzk_transport.lua`, `chzzk_http.lua`, `chzzk_json.lua`, `chzzk_fonts.lua`, `chzzk_overlay.lua`, `overlay.html`이 함께 필요합니다.
2. 이전 Python 수신기를 종료합니다. **start-helper.cmd는 실행하지 않습니다.** bridge.py/start-helper.cmd는 저장소의 이전 방식 참고 파일이며 Lua 전용 배포 ZIP에는 포함하지 않습니다.
3. OBS의 **도구 → 스크립트**에서 `chzzk-chat.lua`를 추가하거나 다시 불러옵니다.
4. 채널 주소/ID를 입력하고 **채팅 폰트** 목록에서 설치된 폰트를 선택합니다. 글자 크기와 채팅 폭·높이도 설정합니다. 새 폰트를 설치했다면 **설치된 폰트 목록 새로고침**을 누르세요.
5. **현재 장면에 채팅 추가 / 설정 적용**을 누릅니다. 기존 브라우저 소스도 새 Lua 수신 주소로 갱신됩니다.

수신은 비로그인 읽기 전용입니다. 로그인·채팅 전송은 지원하지 않으며 로그인/연령 인증이 필요한 채널은 지원하지 않을 수 있습니다. 한 번에 한 채널만 연결합니다.

## 구조 및 동작

- HTTPS로 채팅 채널과 읽기 토큰 조회 → WSS 연결 → 최근 채팅/실시간 채팅 수신을 Lua가 처리합니다.
- libcurl multi와 논블로킹 WebSocket, 30ms OBS 타이머를 사용합니다. 별도 Python/Node/PowerShell 프로세스를 띄우지 않습니다.
- TLS 인증서 검증을 유지합니다. 채팅 토큰을 파일이나 로그에 저장하지 않습니다.
- 브라우저 전달용 서버도 Lua가 운영하며 `127.0.0.1:18766`에만 바인딩합니다. 수신 메시지를 외부 서버로 전송하지 않습니다.
- 최근 100개 메시지, 제재/개별 삭제, 삭제 취소, 중복 방지, 핑 응답과 연결 실패 후 10→20→40→60초 간격 재시도를 지원합니다. 연결 오류 시 기존 메시지를 비웁니다.
- 스크립트 제거/OBS 종료 시 수신 연결과 로컬 서버가 종료됩니다. 게임 위 채팅은 아래 오버레이 기능을 사용할 수 있습니다.

## 지원 환경 및 확인 범위

Windows x64 OBS의 LuaJIT/FFI, WebSocket 지원 libcurl, 브라우저 소스가 필요합니다. 현재 설치 환경의 libcurl 8.12.1-DEV에서 검증했습니다. 다른 OBS 배포판이나 macOS/Linux는 검증하지 않았습니다.

실제 공개 채널에서 Lua로 연결 및 메시지 2개 수신을 확인했습니다. 제재/삭제/취소/중복/목록 제한 회귀 테스트, 로컬 HTTP/HTML 응답 및 Host 검사, 합성 장면 모의 테스트를 통과했습니다. 실제 OBS 장면의 최종 녹화 검증은 아직 필요합니다. 치지직 비공식 웹 채팅 프로토콜 변경 시 업데이트가 필요할 수 있습니다.

개발용 테스트 실행에만 Python을 사용하며, OBS 실행에는 필요하지 않습니다:

```powershell
.\.venv\Scripts\python.exe tests/run_obs_lua.py tests/obs_lua_receiver.lua
.\.venv\Scripts\python.exe tests/run_obs_lua.py tests/obs_compose.lua
```

JSON 파서는 [rxi/json.lua](https://github.com/rxi/json.lua)의 MIT 라이선스이며 `chzzk_json.lua`에 원문을 포함합니다. 통신 구현은 [libcurl multi](https://curl.se/libcurl/c/libcurl-multi.html)와 [WebSocket API](https://curl.se/libcurl/c/curl_ws_recv.html)를 사용합니다.

## 게임 + 채팅을 하나의 출력으로 구성

1. OBS에 **게임 캡처** 소스를 만들고 대상 게임을 지정합니다. 기존 윈도우/디스플레이 캡처도 선택할 수 있습니다.
2. 스크립트를 다시 로드하고 **캡처 소스 목록 새로고침**을 누릅니다.
3. **함께 출력할 캡처 소스**에서 원하는 소스를 선택하고 채널 주소와 채팅 폭을 지정합니다.
4. **녹화 화면 배치**에서 **나란히** 또는 **중첩**을 선택한 뒤 **게임 + 채팅 합성 장면 만들기 / 갱신**을 누릅니다. 배치를 변경할 때도 이 버튼을 누르세요.
5. OBS 장면 목록에서 **CHZZK 게임 + 채팅**을 선택합니다. 스튜디오 모드라면 미리보기 확인 후 전환하세요. 이 장면을 방송하거나 녹화하면 두 화면이 함께 출력됩니다.

기본값인 **나란히**는 왼쪽에 게임, 오른쪽에 채팅을 나누어 표시합니다. **중첩**은 게임을 전체 캔버스에 비율을 유지하여 배치하고 오른쪽에 채팅 카드를 올립니다. 카드 사이의 빈 공간은 투명하므로 게임이 보입니다. 갱신할 때 채팅을 가장 위로 올려 게임에 가려지지 않도록 합니다.

합성 장면의 높이는 OBS 기본 캔버스를 따릅니다. 채팅 폭은 두 모드 모두 캔버스의 절반 이하로 제한합니다. 기존 장면의 게임 배치는 바꾸지 않으며, 소스를 공유하므로 게임 캡처 속성 변경은 공유한 다른 장면에도 적용됩니다. 채팅 소스 역시 공유하므로 폭·높이 갱신이 다른 장면의 같은 채팅 소스에도 반영됩니다.

녹화 시작과 방송 장면 전환은 자동으로 하지 않습니다. 소리는 OBS 오디오 믹서에서 별도로 확인하세요. 별도 미리보기 창이 필요하면 합성 장면의 창 프로젝터를 열 수 있습니다.

합성 로직은 OBS LuaJIT에서 API 모의 객체로 검사했습니다(1920×1080/1280×720 배치, 반복 갱신, 캡처 변경, 폭 제한, 없는 소스 처리). 실제 OBS의 캡처·녹화 검증은 아직 필요합니다.

## 버추얼캠을 합성 장면에 추가

1. 아바타 프로그램의 가상 카메라 출력을 켜고 OBS에 **비디오 캡처 장치** 소스로 등록합니다.
2. Lua 설정의 **버추얼캠 다시 감지**를 누릅니다. 현재 장치 목록에 있는 가상 카메라 소스가 감지될 때만 선택 옵션이 활성화됩니다.
3. **버추얼캠 함께 표시**를 켜고 **감지된 버추얼캠 소스**를 선택한 다음 **게임 + 채팅 합성 장면 만들기 / 갱신**을 누릅니다.

나란히/중첩 모드 모두 게임 영역 왼쪽 아래에 비율을 유지하여 표시합니다. 기본 영역은 게임 폭의 30%, 캔버스 높이의 40%입니다. OBS 미리보기에서 이동·크기를 조절할 수 있지만 합성 갱신 시 기본 배치로 돌아갑니다. 표시를 끄고 갱신하면 이 기능이 추가한 카메라 항목만 합성 장면에서 제거합니다.

감지는 설정 화면을 열거나 다시 감지할 때 수행하며, 합성 적용 시 선택 장치를 다시 검사합니다. 장치가 모두 사라지면 다시 감지 시 표시 설정을 해제합니다. 실행 중 장치 분리를 상시 감시하지는 않습니다. 등록된 드라이버가 있다는 것과 실제 영상 수신 여부는 다르므로 아바타 프로그램을 실행해야 합니다.

Windows DirectShow 장치 이름에 `virtual`, `가상`, `VTube`, `VSeeFace`, `VNyan`, `Animaze`, `FaceRig`, `VMagic`, `V Magic`, `ManyCam`이 포함된 카메라를 인식합니다. 이름 기반 감지여서 다른 이름의 가상 장치는 누락될 수 있습니다. 화면 재귀를 막기 위해 이름에 `OBS`가 포함된 장치는 제외합니다. 일반 웹캠은 가상 카메라로 취급하지 않습니다. 배경 제거는 자동 적용하지 않으며 필요하면 해당 OBS 소스에 크로마키 필터를 설정하세요.

## WebSocket send 55가 반복될 때

전송 오류가 발생하면 해당 연결을 닫고 지연 후 재접속합니다. 같은 오류는 60초마다 최대 한 번 기록합니다. Lua 모듈 캐시도 새로고침 때 갱신하도록 처리했습니다. OBS에서 스크립트를 새로고침한 후 설정 적용을 다시 누르세요. 오류가 계속되면 네트워크/치지직 접속 상태도 확인해야 합니다.

OBS는 전역 `error()`를 예외가 아닌 로그 출력 함수로 교체합니다. 통신/HTTP/JSON 모듈은 자체 예외 함수를 사용하여 실패 시 실행을 중단하고 재연결 처리로 넘깁니다. `tests/obs_error_hook.lua`는 이 OBS 동작을 재현하고, 전송 오류 55 이후 500회 타이머 호출에서 추가 전송/원시 오류 로그가 없음을 검사합니다.

`schannel: timed out sending data (bytes sent: 0)` 대응: HTTPS/WebSocket 연결 단계의 15초 전체 제한을 WebSocket 연결 완료 직후 해제합니다. 이후 세션에는 채팅 응답 70초 감시와 재연결 처리를 적용합니다. HTTP API 조회와 초기 연결에는 기존 제한을 유지합니다.

## 게임 위 전용 채팅 오버레이 · Ctrl+Alt+F8

1. OBS 스크립트를 새로고침하고 채널 설정을 적용합니다.
2. **게임 위 채팅 열기 · 이동/크기 편집**을 누릅니다. 채팅 소스만 표시하는 OBS 창 프로젝터가 열립니다.
3. 창을 원하는 위치로 이동하고 크기를 조절합니다.
4. **Ctrl+Alt+F8**을 누르면 테두리가 숨겨지고 마우스 클릭이 뒤의 게임으로 통과합니다. 다시 누르면 편집 모드로 돌아갑니다. 창이 없을 때 누르면 게임 모드로 엽니다.
5. **게임 위 채팅 숨기기 / 표시** 버튼으로 게임용 창만 숨길 수 있습니다. 방송/녹화 채팅 소스는 계속 표시됩니다.

Windows의 창 모드/테두리 없는 게임용입니다. 독점 전체 화면 위 표시는 보장하지 않습니다. 프로젝터는 항상 위에 표시하며, **게임 위 채팅 불투명도** 설정은 모드 전환 때 적용됩니다. 창 전체의 불투명도를 조절하는 방식이며 배경을 픽셀 단위로 완전히 투명하게 만드는 방식은 아닙니다.

OBS **설정 → 단축키 → CHZZK 게임 위 채팅 · 클릭 통과 전환**에서 키를 변경할 수 있습니다. 기본값은 Ctrl+Alt+F8이며 변경한 바인딩도 저장합니다. 별도 Python 수신기나 독립 실행형 앱은 실행하지 않아도 됩니다.

스크립트 해제 시 오버레이 창 속성을 원래대로 복구합니다. 이 기능으로 새로 만든 OBS 프로젝터 창만 제어합니다. 실제 Windows 창에서 클릭 통과·테두리 제거·표시/숨김·속성 복구를 검사했으며, 실제 게임 위 OBS 프로젝터의 렌더링과 단축키 동작은 현장 확인이 필요합니다.

## 공식 후원 알림 · 영상 후원 오버레이

개발자 앱 등록 없이 치지직 공식 오버레이를 브라우저 소스로 추가합니다. 주인 로그인 상태를 검사하는 기능은 아닙니다. 치지직 스튜디오에서 후원 기능과 알림 설정을 먼저 완료하세요.

1. 치지직 스튜디오의 **방송관리 → 알림**에서 후원 알림 및 영상 후원용 공식 오버레이 주소를 복사합니다.
2. OBS Lua 설정에서 **후원 알림 공식 오버레이 주소**, **영상 후원 공식 오버레이 주소**에 각각 입력합니다.
3. 원하는 **표시** 항목을 켜고 **게임 + 채팅 합성 장면 만들기 / 갱신**을 누릅니다. 끌 때도 표시 해제 후 같은 버튼을 누릅니다.
4. 후원 알림은 게임 영역 위쪽 중앙, 영상은 중앙에 나타납니다. 채팅·버추얼캠과 함께 나란히/중첩 모드에서 사용할 수 있습니다.
5. OBS 오디오 믹서에서 후원 브라우저 소스의 소리·음소거·녹화 트랙을 확인합니다. 이 기능은 브라우저 오디오를 OBS로 보내지만 모니터링이나 트랙 설정을 변경하지 않습니다. 치지직의 테스트 알림으로 영상과 소리를 확인하세요.

주소 입력칸은 마스킹되지만 주소는 OBS 스크립트 및 장면 설정에 저장됩니다. 주소가 포함된 설정 파일을 공개하지 마세요. 로그에는 주소를 출력하지 않습니다. HTTPS의 `chzzk.naver.com` 주소만 허용하며, 주소 형식 검사는 실제 유효성이나 소유권을 보장하지 않습니다.

표시를 끄고 갱신하면 관리 중인 해당 브라우저 소스를 빈 페이지로 바꾸고 합성 장면에서 제거합니다. 같은 소스를 다른 장면에서 공유했다면 그쪽도 빈 페이지가 됩니다. 숨겨진 소스는 종료하도록 설정하므로 장면이 비활성화된 동안 후원 알림의 전달·재생은 보장하지 않습니다. 스크립트 제거가 기존 OBS 소스 삭제를 의미하지는 않습니다.

영상 자동재생·승인·건너뛰기·필터는 치지직 스튜디오와 리모컨에서 설정합니다. Lua가 후원 영상이나 계정 쿠키를 직접 가져오지는 않습니다. 실제 후원 재생은 사용자 오버레이 주소로 OBS에서 확인해야 합니다.

참고: [치지직 영상 후원 공식 안내](https://help.naver.com/service/30044/contents/22984?lang=ko&osType=COMMONOS)

## 미션 후원

치지직 스튜디오에서 미션 후원을 켜고, 알림 메뉴의 **미션 후원 안내 URL**을 복사하세요. Lua 설정의 **미션 후원 공식 오버레이 주소**에 붙여넣고 **미션 후원 표시**를 켠 뒤 **게임 + 채팅 합성 장면 만들기 / 갱신**을 누릅니다.

미션 오버레이는 게임 영역 하단 중앙에 표시합니다(게임 영역 폭의 70%, 캔버스 높이의 25%). 일반 후원·영상 후원과 별도로 켜고 끌 수 있으며, 표시 해제 후 갱신하면 해당 브라우저를 빈 페이지로 바꾸고 합성 장면에서 제거합니다. 기본 위치는 아바타와 겹칠 수 있으므로 필요하면 OBS에서 위치를 조절하세요. 합성 갱신은 기본 위치를 다시 적용합니다.

미션 수락·거절·성공·실패 처리는 치지직에서 진행하며 이 기능은 공식 오버레이 표시만 담당합니다. 주인 로그인 여부는 검사하지 않습니다. 실제 미션 표시와 효과음은 OBS에서 확인해야 합니다.

[치지직 미션 후원 공식 안내](https://help.naver.com/service/30044/contents/23261?lang=ko&osType=COMMONOS)

## 선택형 SOOP 동시 채팅 애드온

`addons/soop4j`의 Java 애드온으로 치지직과 SOOP의 일반 채팅을 같은 패널에 표시할 수 있습니다. Java 11 이상이 필요합니다. 기본 치지직 기능만 사용하면 Java를 설치하지 않아도 됩니다.

애드온 `start.cmd`를 실행해 공개 BJ ID를 입력하고, Lua 설정에서 **SOOP 채팅 함께 표시**를 켠 뒤 같은 ID를 입력하여 적용하세요. 송출 스트림키는 사용하지 않습니다. SOOP 재연결 중에는 메시지를 유지합니다. 애드온 응답이 30초 이상 없거나 방송 ID가 다를 때 SOOP 표시를 비웁니다. 실제 영상 동시송출과 SOOP 제재/후원/구독 연동은 포함하지 않습니다.

자세한 설치·실행·지원 범위는 [SOOP 애드온 안내](https://github.com/NoteBlockMR/GameChzzk-ChatScreen/blob/main/addons/soop4j/README.md)를 참고하세요.
